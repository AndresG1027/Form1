# Form1 - Formulario de Contacto

Un formulario de contacto interactivo y moderno desarrollado con HTML, CSS y JavaScript vanilla.

## Características

- ✅ Validación en tiempo real de campos
- ✅ Diseño responsivo y moderno
- ✅ Validación de correo electrónico
- ✅ Validación de número de teléfono (10 dígitos)
- ✅ Mensajes de error descriptivos
- ✅ Confirmación visual de envío exitoso

## Campos del Formulario

- **Nombre Completo**: 2-50 caracteres, solo letras y espacios
- **Correo Electrónico**: Formato de email válido
- **Teléfono**: 10 dígitos numéricos
- **Asunto**: 3-100 caracteres
- **Mensaje**: 10-500 caracteres

## Uso

1. Abre el archivo `index.html` en tu navegador web
2. Completa todos los campos del formulario
3. Haz clic en "Enviar"
4. Verás un mensaje de confirmación cuando el formulario se envíe correctamente

## Estructura del Proyecto

